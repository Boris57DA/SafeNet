# SafeNet Academy

Образователна игра за киберсигурност за 5.–9. клас. Екип: Борис и Кристиан, 10. клас. Етап 2: начален интерфейс, двуезични мисии и интеграция със Supabase.

## Стартиране

Инсталиран Node.js 22 или по-нов. Отвори терминал в тази папка:

```sh
npm start
```

Отвори http://127.0.0.1:4173. Не е нужно `npm install`: няма локални зависимости. Не отваряй HTML чрез двойно щракване — ES modules изискват HTTP. Алтернатива: VS Code Live Server.

```sh
npm test
```

## Какво работи

- Начало и мисия като два свързани изгледа, адаптивен CSS.
- Три мисии с общо девет отговора, обяснения, точки и ниво.
- BG по подразбиране и EN без загуба на игровото състояние.
- Локално демо с localStorage, ясно обозначено на екрана.
- Подготвен Supabase клиент: четене на мисии/отговори/собствени опити и запис чрез `submit_answer`.
- SQL за три таблици, ключове, RLS и тестово съдържание.

**Реалният Supabase проект още трябва да се създаде и конфигурира. Локалното демо не доказва работа с реална база.** Следвай [SUPABASE_SETUP.md](docs/SUPABASE_SETUP.md). Наличието на SQL файлове не означава, че таблиците вече са създадени в облака.

## Файлове

- `index.html`, `css/style.css`: два изгледа и адаптивен дизайн.
- `js/app.js`, `game.js`: управление на екраните, избора и резултатите.
- `js/translations.js`, `demo-data.js`: преводи и измислени учебни ситуации.
- `js/supabase-client.js`, `config.js`: локален/облачен режим.
- `supabase/`: схема, данни, проверки.
- `docs/`: ER диаграма, тестови инструкции, разпределение, отчет и доказателства.

## Ограничения

Анонимният профил е свързан с браузъра. Изчистване на неговите данни губи достъп до профила. Първият отговор за всяка мисия се зачита; повторно отваряне не дава нови точки. Няма учителско табло, класация или адаптивен алгоритъм в Етап 2. Демо данните не се прехвърлят към Supabase. В облачен режим е необходим интернет, включително за SDK от CDN.
