# Технологичен стек

| Технология | За какво се използва | Защо |
| --- | --- | --- |
| HTML5 | Семантични header, nav, main, section, article, footer | Изискване за Етап 2; четима структура |
| CSS3 | Grid, Flexbox, media queries, фокус и responsive дизайн | Един отделен файл, без UI framework |
| JavaScript ES modules | Навигация, избор, BG/EN, точки, състояние | Лесни за проследяване модули |
| Supabase PostgreSQL | scenarios, choices, attempts | Релационни данни с PK/FK и ограничения |
| Supabase Auth | Анонимна сесия | Без имейли и пароли на ученици |
| PostgreSQL RLS и RPC | Собствени опити; сървърна оценка на отговор | Клиентът не задава чужд user_id или точки |
| supabase-js 2.49.1 | Достъп до Auth, REST и RPC | Фиксирана CDN версия, MIT лиценз |
| localStorage | Само демо резултати; Auth сесията се управлява от SDK | Работа на прототипа преди настройка на облака |
| Node.js 22+ | Локален HTTP сървър и вграден node:test | Няма npm зависимости и build процес |
| Git / GitHub | История, Issues, работа на двама | Проследим принос |
| GitHub Pages (по избор) | Статично публикуване | Supabase остава отделната база |

Няма React, Vite, собствен backend или инсталация на пакети. Supabase RPC е сървърната логика. Системни шрифтове и собствена CSS илюстрация; няма външни изображения или платени активи.
