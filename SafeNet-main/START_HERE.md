# Започни оттук

## Отваряне на проекта

Отвори терминал в тази папка, изпълни `npm start` и посети http://127.0.0.1:4173. Нужен е Node.js 22+. Алтернатива: VS Code → Open Folder → тази папка → Live Server върху index.html. Няма npm install и build.

## Какво да направите преди предаване

1. Създайте Supabase проект. Следвайте docs/SUPABASE_SETUP.md.
2. В SQL Editor изпълнете последователно supabase/schema.sql и supabase/seed.sql.
3. Включете anonymous sign-ins. Попълнете публичните URL/key в js/config.js.
4. Тествайте реален отговор и вижте реда в attempts. Добавете доказателство в docs/evidence.
5. Прегледайте docs/COMMITS_AND_ROLES.md: там са точните файлове и commit команди за Борис и Кристиан.
6. Копирайте проекта в съществуващото общо GitHub хранилище, запазвайки неговата история. docs/GITHUB_ISSUES.md съдържа задачите за добавяне в Issues.
7. Всеки попълва истинския си принос в WEEK_2_REPORT.md и прави commit през своя профил.
8. Използвайте docs/SUBMISSION_CHECKLIST.md преди Classroom.

## Подготвено

Два екрана, три двуезични мисии, резултати, responsive дизайн, Supabase SQL и клиент, ER диаграма, технологичен стек, тестове, пет реални снимки на локалното демо и инструкции за учителя.

## Все още не е потвърдено

Облачна Supabase база и запис, GitHub Issues и лични commits, публично демо. Това изисква вашия реален проект/хранилище. Файловете не заявяват невярно, че тези действия вече са изпълнени.
